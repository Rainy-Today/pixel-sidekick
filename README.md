# Pixel Sidekick · 桌面伙伴

「桌面伙伴」是给 Cindy 做的 Windows 像素桌宠。遇到看不懂的报错或设置，可以框选屏幕上的一块区域，带着截图问 Cindy，在桌面浮窗里看回复。平时也可以用语音听写，或者看一眼任务进度。

## 安装

支持 Windows 10 / 11 x64 和 Cindy 0.1.140 或更新版本。

- 打开 Cindy 的「插件」页，在插件市场搜索 **桌面伙伴**，即可直接安装。
- 如果想手动安装，也可以从 [GitHub Releases](https://github.com/Rainy-Today/pixel-sidekick/releases/latest) 下载 `.cindy` 安装包，再在 Cindy 的「插件」页选择「从文件安装…」。

安装后，从 Cindy 左侧导航打开「桌面伙伴」。
